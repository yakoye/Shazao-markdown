## Hello, Shazao

```python
from pathlib import Path

def hello_shazao(folder: str) -> None:
    notes = sorted(Path(folder).glob("*.md"))
    for number, note in enumerate(notes, start=1):
        print(f"{number:02d}  {note.stem}")

hello_shazao("demo")
```
