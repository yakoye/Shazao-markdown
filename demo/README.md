## 一分钟演示

1. 打开「你好，沙枣」，从一行文字开始，展示直接编辑与源码切换。
2. 切到「把想法画出来」，展示图表与公式；双击图表查看细节，再返回原位。
3. 切到「代码与计划」，展示表格、语法高亮与多标签。
4. 切换浅色、深色与预设配色，最后用「慢下来，读一页」展示阅读排版。

面向初次了解软件的观众，可以先讲「小而快，也完整」，再打开「表格，不止能看」实际操作。文字介绍配合真实操作，比堆叠功能名称更直观。

## 截图约定

- 使用实际程序窗口，记录拍摄版本；示例本身不写死版本号。
- 同一组截图尽量保持一致的窗口尺寸、字号与侧栏宽度，正文从顶部开始。
- 保留标题栏、多标签、大纲与状态栏，让人能看清真实的软件界面。
- 每张图有一个重点，避免把所有功能挤在一屏；重要内容不要截断在窗口边缘。
- 关闭菜单、查找框和悬浮提示后拍摄，不包含私人文件或运行记录。
- 成图放在 [`doc/images/readme/`](../doc/images/readme/)，中英文 README 共用。图片只做裁边或尺寸整理，不拼造软件功能。
