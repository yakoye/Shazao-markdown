## v0.6.17 — Base64 图片与单文件导出、文件树移动、表格单元格编辑

Windows x64 便携版。

### 新功能

- **Data URI 图片（Base64）**：`![图](data:image/png;base64,...)` 写在正文里即可显示，支持 PNG、JPEG、GIF、WebP、SVG。无法显示时改为显示源码，鼠标停在上面时状态栏说明原因（无效字符及位置、数据被截断、超过大小上限、不是图片、图片损坏、缺少 WebP 解码器、类型与内容不符）。
- **导出 ▸ Markdown（单个文件，图片内嵌）**：把文档中的本地图片写成 Data URI，生成一个新的 .md，发给别人也能看到图片。已是 Data URI 的不重复编码，网络图片保留原地址，读取失败的图片逐项列出、确认后才导出；原文档不变。
- **在文件树中移动文档**：把文件拖到文件夹行的中间移入该文件夹（拖到行的上下边缘仍是调整顺序），或右键“移动到…”。一起更新图片路径、资源目录和其他文档中指向它的链接；也可整体移动文件夹。同名、移到自身或子文件夹、没有权限等情况说明原因并保持原样。
- **标签页右键菜单重排**：在右侧新建、在新窗口中打开、移动文档 ▸（移动到最前 / 最后）、固定、复制文件完整路径、打开所在文件夹、复制全部内容、重命名、移至回收站、重新加载、打印…、关闭、关闭其他、关闭右侧。在不是当前的标签上执行时作用于该标签。
- **表格单元格清空与粘贴**：选中的单元格、整行、整列按 Delete、Backspace、右键删除或剪切，只清空文字，表格保留。复制的单元格（也可从电子表格复制）在任意单元格粘贴，从该单元格起逐格写入，行不够时自动补行。
- **折叠标题的等级标记竖排**：开启等级标记时，折叠的标题标记逆时针转 90°、用强调色，展开后恢复横排。

### 修复

- 表格中插入或删除行列、合并拆分、对齐、排序、清空、粘贴之后，表格停在原来的屏幕位置，不再跳到窗口最下方；排序后光标留在原来的行。
- 引用和提示块（Tip、Note 等）中回车新起段落，不再多下移一行；段落间距与正文相同。
- 段落末尾按 Shift+回车后稍作停顿，光标不再回到上一行、接着输入的文字也不再接到上一行末尾（正文、引用、提示块、列表项；v0.6.16 也有此问题）。
- 固定的标签页保留文件名，名字前加图钉。
- 编辑视图中删除分割线：文末分割线下面的空行按 Backspace、分割线下紧接代码块或表格时在其开头按 Backspace、鼠标拖选从分割线开始或停在分割线上，都能删除分割线；选区包含分割线时按 Backspace / Delete 不再响系统提示音。
- 复查其余对话框与列表滚动条的浅深色（设置、代码语言、标签搜索、插入序列、历史比较），均随配色。

### 已知问题

- 粘贴的单元格超出表格右侧时，多出的列略去并提示（行会自动补）。v0.6.18 将改为自动补足所需的列，不丢数据，整次粘贴一次撤销。
- 只在分割线这一行内左右拖动不会形成选区，此时 Backspace 不删除分割线（不响提示音；Delete 可删除）。v0.6.18 修复。
- 标签页拖出成独立窗口、拖到另一个窗口合并、“移动到 xx 窗口”在 v0.6.18；“移动到另一视图 / 复制到另一视图”需要窗口分栏，在 v0.7.0。PELE 部分图形文字错位在 v0.6.18 先查明原因。

### 使用说明

解压后运行 `Shazao-markdown.exe`。版本由目录与 ZIP 名区分，EXE 文件名保持不变。第三方组件说明随包提供。

验证：整版 348 步首次 346 通过、2 失败，产品 EXE 不变的情况下逐项复验通过（图片源码提示在 850×450 窗口一次未找到提示区域，重跑 3/3 各 26/26；picture 回退缺 pdfplumber，换用项目此前的 Python 47/47）；核心 CTest 51/51、编辑 301 项、光标全位置扫描 26,462 项、表格单元格 396 项、测试套件 45 篇 7,945 项通过；本版新增的分割线删除、表格不跳动与清空粘贴、表格其余操作测试共 374 项通过。原始失败记录保留，不称首轮全绿。不同物理 DPI、多显示器未单独验证。


## v0.6.16 — 正文标题折叠、侧栏与标签页修复

Windows x64 便携版。

### 修复

- 文件侧栏单击或双击打开文件时，侧栏不再闪一下（原来每次打开都重新套用侧栏主题，文件树被擦空到新文档读完才重画）。
- 暗色模式下，标签页的文件名/路径提示改为深色。
- 点击图片上方的源码提示，源码框出现在图片上方；点击下方的提示，在下方编辑，不再先跳到底部。
- 标签页右键“关闭其他标签页”“关闭右侧标签页”等六个命令恢复有效（v0.6.15 中与侧栏排序命令编号重叠，点击后执行的是排序）。
- 文件、最近、收藏三个侧栏页面的行高与大纲一致，跟随大纲字号、行距与界面缩放。

### 新功能

- **正文标题折叠**：鼠标停在标题行上显示控件，点击折叠或展开该标题下的内容。开启“标题级别标记”时控件就是 H1/H2… 标记，关闭时是与文件侧栏相同的下三角/右三角；折叠后控件改用强调色并保持显示，标题末尾显示“···”。折叠只影响显示，查找、大纲跳转、编辑和导出仍使用完整内容，跳到折叠处时自动展开。
- **一级/二级标题底部分隔线**：设置 → 外观中分别开启（参照 GitHub 默认样式，默认关闭）。导出 HTML/PDF 时标题下方照旧带线。
- **大纲无标题时自动收起侧栏**：设置中开启（默认关闭）。侧栏停在大纲页面而当前文档没有标题时收起，切到有标题的文档时恢复；收起期间手动打开侧栏后，这篇文档不再自动收起。
- **关于窗口**显示程序图标，项目主页与发布页可点击，也可用 Tab 选中后回车打开。
- **帮助 → 示例与语法**：以只读窗口打开内置的示例与语法文档。

### 使用说明

解压后运行 `Shazao-markdown.exe`。版本由目录与 ZIP 名区分，EXE 文件名保持不变。第三方组件说明随包提供。

行内代码文字颜色可在设置 → 外观中分别为浅色和深色设置（已有功能，本版补了测试）。选中目录闪烁问题用屏幕实际像素方法复测未能复现，本版不列为已修复。PELE 部分图形（类图命名空间、实体关系图、Event modeling）的文字错位已记录，在后续版本中先查明原因再修复。Base64 单文件导出、文件树中移动文档、检查更新、自动保存开关、Ctrl+D 多处编辑仍在后续计划中。

验证：整版 340 步首次 337 通过、3 失败，产品 EXE 不变的情况下逐项复验通过（代码语言选择因测试开始时另一窗口在前台未进入场景，重跑 3/3；字体字形一次粗体未写入设置，重跑 3/3；picture 回退缺 pdfplumber，换用项目此前的 Python 47/47）；核心 CTest 50/50、核心断言 336/336、光标全位置扫描 26,462 项、测试套件 45 篇 7,945 项通过。原始失败记录保留，不称首轮全绿。不同物理 DPI、多显示器未单独验证。


## v0.6.15 — 图表、工作区与编辑体验

Windows x64 便携版。

### 图表与图片阅读

- 扩展 Mermaid 图表支持，集成离线 PELE 渲染；修复点击图表或源码后，滚轮位置变化但正文画面停住的问题。
- 单击已绘制的 Mermaid 保持图形与位置；右键“编辑图表源码”进入编辑。
- 双击 Mermaid 或正文独立图片进入查看，滚轮缩放、拖动查看细节，双击切换 100% 与适应窗口；按 Esc 或点击图外返回原位。
- 图片源码条按可见空间切换上下位置，并显示只读的文件大小、分辨率及显示比例。

### 文件与工作区

- 多选 Markdown 文件拖入时全部打开；拖入文件夹递归打开其中的 Markdown，并切到文件侧栏。
- 命令行传入目录或 `.`，可将该目录作为工作区根目录；不同文件夹采用独立窗口，同一根目录复用已有窗口。
- 文件树和收藏支持名称、修改时间正倒序及拖动手动排序，重启保留顺序。
- 设置 → 阅读新增“显示隐藏文件/点目录”，默认关闭；开启后可展开和搜索 `.agents/skills`、`.github` 等目录中的 Markdown。
- 外部打开新文件默认加入已有窗口标签。设置 → 编辑 → 打开文档可切换为新窗口；Ctrl+N 保留原有行为。

### 编辑与界面

- 修复中文输入法候选栏锚点、大纲条目间距，以及状态栏重复显示链接标题的问题。
- 增加独立的“允许滚动超过文档底部”设置，无需开启打字机模式。
- 减少侧栏切换时的设置写入开销；统一文件、大纲、最近、收藏四个侧栏的浅深色滚动条。
- 修复标题栏捕获鼠标期间，无按键的移动消息误触发拖窗、导致 Escape 意外切到只读的问题。

- 修复字体选择的粗体/斜体未生效，正文和代码字形可分别设置。
- 改进长内容及合并表格的自适应列宽，保留手动列宽优先。
- 关闭前若还有尚未写入文件的输入，提供保存、不保存、取消；保存失败保留窗口。已自动保存的正文不重复询问。

### 使用说明

解压后运行 `Shazao-markdown.exe`。版本由目录与 ZIP 名区分，EXE 文件名保持不变。第三方组件说明随包提供。

图片查看目前覆盖 Mermaid 和正文独立图片块；表格内部及任意行内小图不在本轮范围。PELE 兼容性已有样例检查，但不承诺所有图形语义完全一致，也未证明比原实现更快。其他输入法、跨物理 DPI 和更多格式继续单列验收。

Ctrl+D 多处编辑、空大纲自动收起、自动保存开关、Base64 单文件导出、帮助更新、标题折叠等仍按逐项清单后续开发，本版没有将其列为已完成。

## v0.5.7 — 其余文件操作：选择编码重新打开、属性、删除、导入、打印、保存全部、恢复草稿

- **更多的编码**：除 UTF-8（带或不带 BOM）与 GB18030 外，新增读写 UTF-16（LE / BE，带 BOM 或不带：按文件中的零字节识别）。不是 UTF-8 的文件在内部按它的文字处理，每次编辑都把整篇按文件原来的编码写回（BOM 与换行符照旧）；文件的编码写不下的字符（如在 Big5 文件中输入简体字）不会写成问号——这次编辑不写入，提示指出是哪个字。此前 GB18030 文件中只有一两个字的段落可能显示成别的字符（它们的字节恰好也是合法的 UTF-8，如「模」显示成「ģ」），现在整篇按 GB18030 读取。UTF-8 文件照旧按原字节编辑，未改动的部分逐字节不变。
- **文件 ▸ 选择编码重新打开 ▸**：按选定的编码重新读取文件（不写入）——从磁盘重新加载、自动检测，以及 Typora 列出的 22 种编码：UTF-8、UTF-16 LE / BE；Windows-1252（西欧）、Windows-1251、IBM866、IBM855、KOI8-R、MacCyrillic（西里尔文）、ISO-8859-2、Windows-1250（中欧）、Windows-1253、ISO-8859-7（希腊文）、Windows-1255、ISO-8859-8（希伯来文）；GB2312 / GBK、GB18030（简体中文）、Big5（繁体中文）、Shift-JIS、EUC-JP（日文）、EUC-KR（韩文）、TIS-620（泰文），分三组；系统代码页不在其中时也列出；当前编码打勾。繁体中文、日文、韩文、俄文文件常被当成 GB18030 或 UTF-8 而显示成乱码，选对编码即正常显示，之后的编辑按这个编码写回。文件中有不是所选编码的字节时不重新打开，文档保持原样并说明原因。重新打开后撤销记录清空（与外部修改后重新载入相同）。
- **从磁盘重新加载**（选择编码重新打开的第一项）：先写入还未写入的输入，再读回文件；选择过的编码保留（自动重新载入外部修改时同样保留；其他程序改用别的编码写入、所选编码读不了时，按检测到的编码读入，不会每次都失败）。

## v0.5.5 — 便携：历史版本与图片缓存放在程序旁

- **历史版本放在程序旁**：文档的历史版本不再默认保存在 `%LOCALAPPDATA%\Shazao\History`，而是保存在程序所在文件夹的 `Shazao-history` 中，与 `Shazao.ini`、`Shazao-shortcuts.ini` 放在一起——把这个文件夹整个拷走，设置、快捷键、最近文件与历史版本都跟着走。程序所在的文件夹不能写入时（如放在 `C:\Program Files`），照旧保存在 `%LOCALAPPDATA%\Shazao\History`；`Shazao.ini` 的 `[History] Folder` 仍可指定别的位置。
- **以前的版本照样能看到**：此前保存在 `%LOCALAPPDATA%\Shazao\History` 的版本留在原处（不搬动、不删除），文件 ▸ 历史版本… 把它们与新版本一起列出，同样可以恢复、查看、复制；以后的新版本只写到新位置，旧的按原来的规则过期。确认不再需要时，可以自行删除旧文件夹。
- **图片缓存放在程序旁**：网络图片的缓存放在程序旁的 `Shazao-cache` 中（不能写入时照旧在 `%LOCALAPPDATA%\Shazao\Cache`）。
- **最近文件**：本来就保存在程序旁的 `Shazao.ini`（`[History]` 节），不变。

## v0.5.3 — 折叠时内容不动、空代码块的行号、围栏按 CommonMark、文档整理到 doc/

## v0.5.1 — 历史版本

- **版本号**：自本版起改为三段式「主.次.修订」：每次交付修订号加一（0.5.1、0.5.2……），一组较大的功能完成时升次版本号（0.6.0），rc 只在大版本发布前需要试用时使用。本版即此前计划的 v0.4.32-rc1。
- **为什么需要**：Shazao 的每次编辑都会立即写回文件，之前的内容只留在本次的撤销记录里，关闭后就找不回来了，被其他程序改掉的内容也一样。现在 Shazao 会在后台保存文档的历史版本：打开文档时保存一次，编辑时每隔 10 分钟在下一次写入前保存一次，文件被其他程序修改而重新载入前保存一次，恢复某个版本前也先保存一次；内容没有变化时不会重复保存。
- **文件 ▸ 历史版本…**：弹出菜单列出这个文档的各个版本（新的在前），每行写着保存的时间（今天 / 昨天 / 日期）、大小，以及恢复后会增加 / 去掉的行数（与现在相同时注明）。点一行打开该版本的菜单：**恢复此版本**（文档回到那时的内容，Ctrl+Z 一步撤销，锁定视图中不可用）、**在新窗口中查看**（以只读方式在新窗口打开该版本的副本，可以对照或复制其中一部分）、**复制全文**；底部可打开历史版本文件夹。
- **保存在哪里**：`%LOCALAPPDATA%\Shazao\History` 下每个文档一个文件夹（以文件名和完整路径的散列命名，文件夹中的 `document.txt` 注明是哪个文档），每个版本是当时文件的原样字节；每个文档最多保留 50 个，超过 30 天的版本自动删除（最新的 10 个总保留）；超过 32 MB 的文件不保存版本。`Shazao.ini` 的 `[History]` 节可以设置 `Enabled`（是否保存）、`Minutes`（编辑中保存的间隔，0 为每次写入前）、`Keep`（最多保留几个）与 `Folder`（保存位置）。
- **测试**：新增 `ShazaoHistoryTests`（文档的文件夹不分大小写且可读、保存与读回、文件夹注明所属文档、相同内容只存一次、同一时刻的版本各有名称、按个数与按时间清理且最新的几个总保留、增删的行数、版本时间与大小的写法）与 `tests/e2e_history.py`（真实程序：打开与编辑前保存、弹出菜单列出版本、点选后恢复与 Ctrl+Z 撤销、恢复前的内容也成为版本、在新窗口中查看写出的副本、复制全文、历史文件夹中的文档不保存版本、关闭后不保存）；右键菜单模型快照随文件菜单的新项更新（30 个菜单各多一行「历史版本…」，其余不变）；新增 `tests/verify_v051.py`。所有端到端测试的窗口把历史版本存在测试自己的临时文件夹中，不写进使用者的 `%LOCALAPPDATA%\Shazao\History`。
