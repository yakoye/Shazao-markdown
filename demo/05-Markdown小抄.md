# Markdown 小抄

**先会一点，就能写很多。**

## 写标题

用 `#` 写一级标题，`##` 写二级标题。把长文分成几个小节，大纲就有了方向。

## 给文字一点重点

**加粗**写重点，*斜体*写旁注，==高亮==标记值得回看的地方，`行内代码`表示命令或名称。

## 把事情列出来

1. 先说清要解决的问题。
2. 再整理需要采取的步骤。
3. 最后留下结果与下一步。

- [x] 建立一份文档
- [ ] 补齐示例
- [ ] 分享给需要的人

## 引用与提示

> 引用一段话，也给自己的思考留一点位置。

> [!TIP]
> 需要精确调整语法时，可以切换到源码模式。

## 链接、表格与代码

[回到第一份示例](01-你好，沙枣.md)，或者看看[代码与计划](03-代码与计划.md)。

| 写法 | 用途 |
| :--- | :--- |
| `[文字](地址)` | 插入链接 |
| `![说明](图片路径)` | 插入图片 |
| 三个反引号与语言名 | 插入带语法高亮的代码块 |

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, Shazao!\n";
    return 0;
}
```
