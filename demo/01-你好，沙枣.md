# 你好，沙枣

**从一行文字，到一份作品。**

记下一闪而过的想法，理清一件复杂的事，或者只是安静地写完今天。

> [!TIP]
> 在排版好的内容里直接写。想看看文字背后的结构？随时切换到源码。

## 先写下一件小事

- [x] 留下一个值得记住的想法
- [x] 给文字一个清楚的标题
- [ ] 把这一页，写成自己的故事

## 让想法有条理

| 想做什么 | 从哪里开始 | 可以带走什么 |
| :--- | :--- | :--- |
| 整理笔记 | 标题、大纲与链接 | 一份清楚的记录 |
| 解释方案 | 图表、公式与表格 | 一份读得懂的说明 |
| 分享作品 | 排版与导出 | HTML、PDF、Word、EPUB |

**重要的事，加粗记住。** 用 `Markdown` 留下结构，也用 ==高亮== 留住灵感。

---

你好，世界。你好，沙枣。
