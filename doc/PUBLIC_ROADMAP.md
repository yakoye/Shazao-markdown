# 沙枣后续开发计划

本页集中记录已经公开的版本安排与后续方向。计划会随反馈和实际验证调整；已交付的内容见[版本历史](CHANGELOG.md)。

## 已公开的版本安排

以下安排在 v0.6.18 发布时更新；未完成的项目顺延，不表示这些功能已经全部完成。

| 版本 | 计划 |
| :--- | :--- |
| v0.6.18（已发布） | 已完成：粘贴单元格自动补足行列；分割线一行内拖动选中并删除；PELE 图形文字错位与发虚；另加界面语言、设置搜索、查找“仅在选区”、图中文字选中复制、侧栏面板快捷键、图片目录自定义路径等，详见[版本历史](CHANGELOG.md) |
| v0.6.19 | 标签页拖出成新窗口、拖入另一窗口合并；检查更新并下载新版本；侧栏开合与大量标题首次填充提速（由 v0.6.18 顺延） |
| v0.7.0 | 窗口分栏，每栏一组标签，标签可在两栏间移动或复制；自动保存开关；Ctrl+D 多处选择同时编辑 |
| 以后 | Mermaid / PELE 图形语义继续扩展；程序体积精简 |

## 持续打磨的方向

- 增加 Ctrl+D 累加选择与同时编辑，完善自动保存控制。
- 继续打磨标签与窗口之间的移动、表格编辑，以及图表文字布局。
- 改进 Wiki 链接的使用体验。
- 完善检查更新与帮助说明，继续校对英文与繁体中文界面。
- 持续推进大图与更多 Mermaid/SVG 特性的兼容，以及输入法、多 DPI 和导出分页的验证。

稳定性与数据安全优先，按反馈逐项开发、验证。新版本的实际完成范围和已知问题，以对应的[发布说明](https://github.com/yakoye/Shazao-markdown/releases)为准。
