# 把想法画出来

**几行文字，也能说清一张图。**

让步骤、关系和公式留在同一份文档里。图旁边就是说明，读者不用来回寻找。

## 从灵感到作品

```mermaid
flowchart LR
    A[一闪而过的灵感] --> B[记下一行文字]
    B --> C{理清思路}
    C --> D[画出关系]
    C --> E[补上细节]
    D --> F[分享一份作品]
    E --> F
    classDef seed fill:#26483E,stroke:#73CBA5,color:#E5FFF3
    classDef note fill:#223F61,stroke:#79B7F5,color:#E9F4FF
    classDef think fill:#493663,stroke:#C7A2F0,color:#F6EEFF
    classDef detail fill:#4F4429,stroke:#D4BB75,color:#FFF6DF
    classDef done fill:#1F4E54,stroke:#67C8CF,color:#E9FFFF
    class A seed
    class B note
    class C think
    class D,E detail
    class F done
```

## 用公式，写下规律

一条优美的等式，可以把很多话收进一行：

$$
e^{i\pi}+1=0
$$

也可以把公式放进句子里：当 $a^2+b^2=c^2$，三条边便围成了一个直角三角形。

> [!NOTE]
> Mermaid 图表与数学公式可以直接阅读；需要修改时，回到各自的源码即可。

让图表负责结构，让文字保留温度。
